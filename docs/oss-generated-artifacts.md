# OSS FunctionUnit generated artifacts

## Source and runtime contract

The following files are deterministic generated runtime ledgers:

- `docs/oss-function-units.lock.json`, generated by
  `python scripts/census_oss_function_units.py`;
- `app/data/oss_function_unit_dispositions.json`, generated by
  `python scripts/build_oss_function_unit_dispositions.py`.

They are intentionally versioned. A clean checkout, the backend runtime and the
production image read them fail-closed, while the pinned upstream source trees
under `.vendor/upstreams` are deliberately not committed. Keeping only the
generators would therefore make a clean clone unable to start or verify the
catalog without first fetching and materializing external upstreams.

The two ledgers form a reviewed fixed point: the census applies the exact-ID
disposition policy and the disposition builder validates/materializes mappings
against the resulting census. They must be regenerated and reviewed together;
neither file is an independent human-authored input.

Large proof fixtures, verification manifests and source snapshots are not
source artifacts. They belong under `.local/qa-evidence` and must not be
committed.

## Required checks

Run with the repository's supported Python version:

```bash
python scripts/build_oss_function_unit_dispositions.py --check
python scripts/census_oss_function_units.py --check
python scripts/verify_oss_function_unit_release.py
```

The census reads canonical bytes from the locked Git commit trees. Verification
must remain bounded and must not turn ignored caches in a materialized checkout
into runtime input. Any change in a ledger must update its embedded digest and
pass all three checks.

## Git policy

`.gitattributes` marks both ledgers as generated and disables textual diffs so
GitHub does not render roughly 1.3 million generated lines during review. Git's
pack compression keeps their transfer size bounded. Before the first remote
publication, the candidate history must be created from the final clean tree so
obsolete generated proof artifacts from local history are not published.
